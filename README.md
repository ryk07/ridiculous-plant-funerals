# Ridiculous Plant Funerals

Entry for the make.fun bounty [Ridiculous at First Glance, Real by the Second](https://make.fun/c/u-po-pu-ridiculous-at-first-glance-real-by-the-second-9a97d12a).

The program writes one sentence pitching a bizarre startup idea — funerals for dead houseplants — to `/output/entry.txt`. The pitch names the odd thing being sold, who pays for it, and why the business holds together.

Run it:

```sh
python3 main.py
```
